#  GeoLogInsight - Real-time GIS Dashboard

This project simulates real-time traffic using randomized log generation.

A real-time log visualization system that displays API traffic on a world map using geolocation.

##  Features

-  Real-time data streaming using SignalR
-  Interactive map powered by Leaflet
-  Heatmap visualization of traffic density
-  Dynamic marker updates
-  Simulated traffic with randomized logs

##  Tech Stack

- ASP.NET Core (.NET 8)
- SignalR
- JavaScript (Vanilla)
- Leaflet.js
- Leaflet.heat

##  What it demonstrates

- Real-time communication (WebSockets)
- GIS data visualization
- Frontend + Backend integration
- Performance considerations for live updates
